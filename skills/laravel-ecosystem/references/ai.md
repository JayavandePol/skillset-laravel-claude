# AI: Laravel Boost & the Laravel 13 AI SDK

## Laravel Boost — make agents version-aware in each project

```bash
composer require laravel/boost --dev
php artisan boost:install      # pick Claude Code; generates guidelines (CLAUDE.md/AGENTS.md), skills, .mcp.json, boost.json
php artisan boost:update       # after adding packages / upgrading
```

- Boost's MCP server (`php artisan boost:mcp`) gives the agent: app info, routes, schema, Tinker, logs, browser logs, and a docs search over version-matched Laravel ecosystem docs.
- Boost guidelines and this skill library complement each other: Boost knows the *installed versions' APIs*; these skills hold *your rules and protocols*. When they conflict on an API detail, trust Boost/docs; when they conflict on a policy (security, structure), follow these skills and record the decision.
- Generated Boost files are regenerated by `boost:update`; the docs suggest gitignoring them. Put durable project rules in your own `CLAUDE.md` section or Boost's project rules feature (13.x docs).

## Laravel 13 AI SDK

First-party unified API for text generation, structured output, embeddings, images, audio, and vector stores across providers. Check https://laravel.com/docs/13.x for the package name and API before use.

Rules (ECO-11):
- Keys in config/env; never expose to the frontend.
- Long generations → queued job + broadcast/polling, or streamed responses; set timeouts.
- Rate limit per user/tenant and track token usage/costs per tenant (store usage records).
- Minimise personal data sent to providers; document processors in the DPA; prefer EU-hosted endpoints when available.
- Treat model output as untrusted input: validate structured output against a schema, escape/sanitise before rendering, never execute it or use it in raw SQL.
- Prompt injection: don't give models tools with side effects on user data without confirmation steps.
- Embeddings + pgvector for semantic search: store vectors in a separate table keyed by model id + tenant id; re-embed on content change via queue.
- Tests: fake the AI client (the SDK provides fakes — check docs) — never hit real APIs in CI.
